# contact-sales-shadow-ban

お問い合わせフォームに送られてくる**特定ドメインからの営業メッセージ**を、Google Tag Manager（GTM）だけで静かにブロックするスクリプトです。

- メールアドレスのドメインがブラックリストに一致したら、**フォームを送信せずに完了ページへリダイレクト**します
- 相手には通常どおり送信完了したように見え、こちらにはデータが届きません（シャドウバン）
- バックエンド不要です。STUDIO・Wix・WordPress など、GTM を入れられるサイトならどこでも使えます
- エラーが起きた場合は通常どおり送信されます（fail-open）。フォームが壊れることはありません

> 🤖 AI エージェント（Claude Code など）でセットアップする場合は [AGENTS.md](./AGENTS.md) を読ませてください。

## 設定項目

| 設定 | GTM 変数名 | 例 |
|---|---|---|
| ブラックリスト | `営業ブロック - ドメイン` | `example-sales.co.jp, spam.jp` |
| 完了ページの URL | `営業ブロック - 完了URL` | `/thanks` |
| メール欄のセレクタ | `営業ブロック - メールセレクタ` | `input[type="email"]` |

## セットアップ

### 方法 1：インポート（おすすめ）

1. `config.json` を編集します

   ```json
   {
     "domains": ["example-sales.co.jp", "spam.jp"],
     "redirectUrl": "/thanks",
     "emailSelector": "input[type=\"email\"]"
   }
   ```

2. ビルドします（Node.js 18 以上。依存パッケージはありません）

   ```bash
   node scripts/build.mjs
   ```

   `gtm/container.json` と `dist/demo.html` が生成されます。

3. `dist/demo.html` をブラウザで開いて、ブロック対象のアドレスでは「ブロックされました」、それ以外では「通常送信されました」と表示されることを確認します
4. GTM の「管理」→「コンテナをインポート」で `gtm/container.json` を選び、**「統合」→「競合するものの名前を変更」**でインポートします
5. GTM の「プレビュー」で実際のフォームを確認してから「公開」します

### 方法 2：手動

1. GTM で「変数」→「ユーザー定義変数」→「新規」から、種類「定数」の変数を上の表のとおり 3 つ作ります（変数名は完全一致させてください）
2. 「タグ」→「新規」→「カスタム HTML」に [`src/tag.html`](./src/tag.html) の中身を貼ります
3. トリガーは「DOM Ready」にします（フォームのあるページに絞っても OK）
4. プレビューで確認してから公開します

## ブラックリストにドメインを追加する

GTM の変数 `営業ブロック - ドメイン` の末尾に `, newdomain.co.jp` と追記して**公開**するだけです。

- `@` は付けても付けなくても構いません
- サブドメインも対象になります（`example.co.jp` を登録すると `mail.example.co.jp` もブロック）
- 区切りはカンマ、スペース、改行のどれでも構いません

リポジトリでも管理したい場合は、`config.json` も同じように更新してコミットしてください。

## 設定のコツ

- **完了 URL** は、通常送信したときに表示される完了ページと同じにしてください。見た目が違うと相手に気づかれます。STUDIO の完了表示が同じページ内のメッセージの場合は、それと同じ見た目の完了ページを別に用意してください
- **メール欄のセレクタ**は、フォームのメール欄を右クリック →「検証」で確認します。たいていは `input[type="email"]` で動きます。1 ページに複数のフォームがあり、メール欄を区別したい場合は `input[name="email"]` のように絞ってください
- `gmail.com` などのフリーメールは登録しないでください。一般の問い合わせまで消えてしまいます

## 制限事項

- ブラウザを経由せず、フォームの送信先に直接 POST してくるツールはブロックできません
- ブラックリストはページの JS に平文で載ります（見ようと思えば見られます）
- サイトの HTML 構造が大きく変わると効かなくなる可能性があります。フォームを改修したらプレビューで再確認してください
